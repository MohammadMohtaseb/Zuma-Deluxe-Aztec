# لعبة زوما ديلوكس: أسطورة الآزتيك (Zuma Deluxe Aztec)

مشروع استنساخ هندسي كامل للعبة **زوما (Zuma)** الكلاسيكية مبني باستخدام **HTML5 Canvas و CSS و Vanilla JavaScript**، مع تكامل **قاعدة بيانات محلية Realm DB**، وجاهز للتشغيل والتحويل لتطبيق سطح مكتب باستخدام إطار عمل **Electron**.

---

## 🌟 الميزات المنفذة وفق وثيقة التصميم الفني (Specification V2.0)

### 1. آليات اللعب (Core Mechanics & Physics)
- **الضفدع الحجري الأسطوري (Stone Frog Idol)**:
  - دوران 360 درجة ناعم يتبع مؤشر الفأرة / اللمس بدقة.
  - عرض الكرة الحالية الجاهزة للإطلاق في الفم.
  - **جوهرة الظهر (Back Gem Buffer)**: تعرض الكرة الاحتياطية التالية، مع إمكانية التبديل الفوري بنقرة الفأرة اليمنى أو زر المسافة `[Space]`.
- **نظام المسار الحركي (2D Spline Path System)**:
  - مسارات هندسية متعددة المراحل محسوبة بدقة (Catmull-Rom arc-length parameterization).
  - حفر وأخاديد حجرية ثلاثية الأبعاد بأسلوب المعابد الآزتيكية.
- **فيزياء سلسلة الكرات وقائمة الاتصال المزدوجة (Doubly Linked Marble Chain)**:
  - تدفق الكرات وتصادماتها بنواقل متجهة.
  - **التجاذب المغناطيسي (Magnetic Pull)**: تراجع الكرات للخلف تلقائياً عند تفريغ فجوة وتطابق لوني الطرفين.
  - **حلقة المكافأة والكومبو (Combos Cascades)**: مضاعفة النقاط وهزات شاشة مع أصوات متصاعدة التردد مع كل كومبو متتالي (x2, x3, x4...).
- **جمجمة الهلاك (Warning Skull Gate)**:
  - تقع عند نهاية المسار، تفتح فكها النابض وتتوهج عيناها باللون الأحمر التحذيري مع إطلاق صفير الخطر عند تجاوز خط الـ 82%.
  - ابتلاع الكرات وفقدان الأرواح عند وصول السلسلة لنهاية المسار.
- **شريط تقدم زوما (Zuma Bar)**:
  - يمتلئ مع كل تدمير للكرات، وعند وصوله 100% يُعلن صياح **"ZUMA!"** ويتوقف تدفق كرات جديدة حتى تطهير المسار للفوز بالمرحلة.

---

### 2. الكرات والقوى الخارقة (Power-ups Blueprint)
1. **💣 كرة التفجير (Bomb Marble)**: تنفجر في محيط دائري مبيدة كل الكرات في محيط واسع.
2. **❄️ كرة الإبطاء (Slow-Down)**: تخفض سرعة حركة الكرات بنسبة 60% لمدة 5 ثوانٍ.
3. **⏪ كرة العودة للخلف (Reverse Ball)**: تجبر سلسلة الكرات بالكامل على التراجع بعيداً عن الجمجمة.
4. **🎯 كرة شعاع الدقة (Accuracy Beam)**: خط ليزر إرشادي متوهج ومضاعفة سرعة انطلاق المقذوفات لاختراق أدق الثغرات.

---

### 3. الهندسة الصوتية التفاعلية (Web Audio API Synthesizer)
- توليد صوتي إجرائي بالكامل بدون أي اعتماد على ملفات خارجية مفقودة.
- **طبول الحرب الآزتيكية التفاعلية**: يتسارع إيقاعها وترددها مع اقتراب الكرات من جمجمة الهلاك.
- أصوات اصطدام الكريستال، الإطلاق، الانفجارات، النفير الاحتفالي لصياح **ZUMA!**، وتصاعد تردد النغمات مع الكومبو.

---

### 4. بنية قاعدة البيانات (Realm DB & Storage Architecture)
- مطابقة تامة لمخططات Realm Object Schemas:
  - **`ScoreRecord`**: حفظ أعلى النتائج، اسم اللاعب، المرحلة، وأعلى كومبو.
  - **`GameProgress`**: حفظ المراحل المفتوحة، إجمالي الكرات المدمرة، والقوى المستخدمة.
  - **`GameSettings`**: حفظ مستويات الصوت، شعاع الليزر، واهتزاز الشاشة.
- **ازدواجية العمل (Dual Operation)**:
  - داخل **Electron**: يتصل مباشرة بـ Realm DB المحلي عبر قنوات IPC الآمنة في `preload.js` و `main.js`.
  - في **المتصفح العادي**: يعمل محرك محاكاة وتخزين محلي IndexedDB/LocalStorage بنفس واجهات برمجة التطبيقات (APIs) لضمان التجربة الفورية في أي بيئة.

## 🚀 كيفية التشغيل

### أولاً: التشغيل المباشر في المتصفح (Web Preview)
يمكنك فتح ملف `index.html` مباشرة في أي متصفح حديث (Chrome, Edge, Firefox)، أو عبر خادم محلي:
```bash
# تشغيل خادم محلي
python -m http.server 8080
```
ثم فتح: `http://localhost:8080`

### ثانياً: التشغيل كتطبيق سطح مكتب عبر Electron (Desktop App)
1. **أيقونة سطح المكتب الرسمية (Desktop Shortcut)**:
   - تم إنشاء أيقونة تشغيل رسمية مسبقاً على سطح المكتب لديك باسم:  
     **`Zuma Deluxe Aztec`**  
     تحمل أيقونة اللعبة الكريستالية الـ 3D، وتفتح اللعبة مباشرة بنقرة واحدة وبدون أي نافذة موجه أوامر سوداء.
   - إذا رغبت بإعادة إنشائها في أي وقت، قم فقط بتشغيل: [`create_shortcut.bat`](file:///c:/Users/user/Desktop/sas/create_shortcut.bat).

2. **عبر موجه الأوامر (Terminal)**:
```bash
npm start
```

## 🎮 عناصر التحكم واختصارات سطح المكتب (Desktop Controls)
- **مفتاح `[F11]`**: ملء الشاشة الكاملة / الخروج من ملء الشاشة.
- **تحريك الفأرة**: تصويب الضفدع الحجري 360 درجة.
- **زر الفأرة الأيسر**: إطلاق الكرة.
- **زر الفأرة الأيمن أو المسافة `[Space]`**: تبديل الكرة بين الفم وجوهرة الظهر الاحتياطية.
- **مفتاح `[P]`**: إيقاف اللعب مؤقتاً.
